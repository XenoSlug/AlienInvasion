# Alien Invasion

Responsive HTML5 arcade shooter.

**Play it now:** https://xenoslug.github.io/AlienInvasion/

The run now continues through escalating enemy waves and repeatable multi-phase bosses. Enemy archetypes include scouts, zigzag fighters, tanks, and bosses with a faster spread-fire second phase.

Controls:

- Move: Arrow keys or A/D; controller left stick/D-pad; touch bottom-left
- Fire: Space/Enter; controller A/RT; touch bottom-right
- Pause/save: P/Escape; controller Menu/Start; press Fire/A to resume
- Permanent upgrade bay: U on the title screen; standard controller Y
- In-run skill menu: K during a run; standard controller X

Run skill purchases spend score. Finishing a run converts score into persistent credits for the upgrade bay.

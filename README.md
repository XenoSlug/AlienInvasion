# Alien Invasion

Responsive HTML5 arcade shooter.

**Play it now:** https://xenoslug.github.io/AlienInvasion/

The game now includes responsive scaling, touch and controller support, controller glyphs, combo scoring, boss fights, save/resume, lives, health, health-refill drops, mid-run skills, permanent meta-progression, and an upgrade bay.

Controls: Arrow keys or A/D to move, Space/Enter or controller A to fire, P/Escape to pause, K for the in-run skill menu, and U for the permanent upgrade bay from the title screen.

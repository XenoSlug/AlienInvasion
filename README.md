# Alien Invasion

Responsive HTML5 arcade shooter.

**Play it now:** https://xenoslug.github.io/AlienInvasion/

Features include responsive scaling, touch controls, keyboard controls, standard Gamepad API support, controller-aware glyphs, combo scoring, boss fights, save/resume, lives, health refills, run skills, and permanent meta-progression.

Controls:

- **Move:** Arrow keys or A/D; controller left stick or D-pad; touch bottom-left controls
- **Fire:** Space/Enter; controller A or RT; touch bottom-right control
- **Pause/save:** P/Escape; controller Menu/Start; touch pause label
- **Permanent upgrades:** U on the title screen; standard controller Y
- **In-run skills:** K during a run; standard controller X

On non-standard controllers, the game displays fallback labels such as `FIRE`, `START`, `4`, and `3` instead of assuming Xbox/PlayStation glyph names.

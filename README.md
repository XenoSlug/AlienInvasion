# Alien Invasion

Responsive HTML5 arcade shooter.

**Play it now:** https://xenoslug.github.io/AlienInvasion/

GitHub Pages is published from the `gh-pages` branch. Controls: Arrow keys or A/D to move, Space/Enter or controller A to fire, and P/Escape to pause. The game includes responsive scaling, touch controls, controller glyphs, combo scoring, boss fights, save/resume, incremental upgrades, and mid-run powerups.
